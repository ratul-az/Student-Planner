# Student Planner Mobile Application

### A Personal Academic Management & Productivity App Built with Flutter

A mobile application designed to help students organize their academic activities, manage assignments, track study schedules, maintain notes, and monitor their study experience in one place.

---

## Overview

The **Student Planner Mobile Application** is a Flutter-based academic productivity project developed to make student life more organized and manageable.

The application brings together essential student-focused tools, including task management, timetable organization, note-taking, reminders, and a mood quiz module.

The goal is to provide students with a convenient digital space to manage their academic responsibilities and daily study activities.

---

## Features

### 1. User Authentication
- Sign-in interface for users.
- Dedicated profile page.

### 2. Task Management
- Manage academic tasks and assignments.
- Organize student responsibilities.

### 3. Timetable & Schedule
- Dedicated timetable interface.
- Organize academic schedules.

### 4. Notes Management
- Create and manage study notes.
- View notes in a dedicated list.
- Mark and access favorite notes.

### 5. Mood Tracker & Quiz
- Interactive mood-related questions.
- Multiple-choice quiz interface.
- Dedicated quiz result page.

### 6. Reminder Management
- Dedicated reminder interface for study-related activities.

### 7. Academic Results & Subjects
- Subject management interface.
- Academic results page.

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or Visual Studio Code
- Android Emulator or a physical Android device

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ratul-az/REPOSITORY-NAME.git
```

**2. Navigate to the project directory**

```bash
cd REPOSITORY-NAME
```

**3. Install dependencies**

```bash
flutter pub get
```

**4. Run the application**

```bash
flutter run
```
